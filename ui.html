Help
What this plugin does

Export variable collections to CSV files for bulk editing in a spreadsheet, then import the edited CSV back to update variable values in your Figma file.

Before you start

Only foundational (non-alias) variables can be exported and imported. Alias variables are shown in the list for context but cannot be selected — they are skipped in the CSV workflow.

How to use it

To export:

1. On the Export tab, use the search and collection headers to find the variables you want. Check individual rows or use the collection-level checkbox to select all foundational variables in a group.

2. Click Export CSV. A download dialog appears with one CSV file per collection. Download each file.

3. Open the CSV in your spreadsheet tool, edit the value columns, then save the file.

To import:

4. Switch to the Import tab and drop or click to upload your edited CSV file.

5. The plugin validates the file and shows a preview: which variables will be updated, which were not found, and which modes are present.

6. Review the preview, then click Confirm Import to apply the changes.

Understanding the output

Each exported CSV contains the variable name, collection, type, and one column per mode. Rows with errors or unrecognised variable names are reported in the validation step and skipped during import.

About

Variable Import/Export — export variable collections to CSV for spreadsheet editing, then import the edited file back into Figma.

Version

1.0.0

Scope

CSV export and import of foundational variables in the current Figma file. One CSV file is generated per collection on export.

Network

No external network access is requested by the plugin manifest.
