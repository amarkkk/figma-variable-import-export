# Changelog

All notable changes to Variable Import/Export are documented in this file.

---

## [1.0.0] - 2025-11-17

### Initial Release

- CSV export for spreadsheet-friendly bulk editing
- JSON export with full variable metadata for backup or programmatic editing
- Multi-mode support (all modes as separate columns in CSV)
- Selective export by collection and variable
- Validation before import with change preview
- Type support for colors (hex), numbers, strings, and booleans
- Download modal for CSV and JSON exports
